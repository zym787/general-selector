# 支持范围

- 232/485
    - 906
        |- AGS
        |- HX
    - 909

# 特性

1. 修复默认参数写入乱码
2. 修改版本号，支持03读版本
3. 初始化降速增扭
4. 超时保护
5. LED报错快闪
6. 默认速度强制设置为20
7. 修复10写临时速度会篡改系统速度
8. LIMIT_TEMP_SPD宏开关限制临时速度

# 版本号说明

## 命名方式
    vX.Y.Z-rN
  - X.Y.Z 为软件版本
  - N 为版次，需要根据此数字区别不同的修改
    eg. v1.3.1A-r1 版本 1.3.1A 版次 r1
    v1.3.1B-r2 版本 1.3.1B 版次 r2
## 软件描述
  下载口会打印: 
    程序版本 修改日期
    本软件描述 (协议)
    电路板版本 电路板描述 (最大电流)

```
 Version:V1.3.1A-r1(1311)  Time: Jul 21 2025 17:29:37
 Description:Switch Valve (232/485+IO)
 PCB:A12-906  Horizontal Version (2.5A Max)
```
