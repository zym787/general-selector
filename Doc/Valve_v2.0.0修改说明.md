# 特性

1. 修复默认参数
2. 修改版本号，支持03读版本
3. 初始化降速增扭
4. 超时保护
5. LED报错快闪
6. 默认速度强制设置为20
7. 修复10写临时速度会篡改系统速度
8. LIMIT_TEMP_SPD宏开关限制临时速度
9. 优化AGS协议栈
10. 支持读写波特率
11. AGS协议栈支持写入参数限制
12. 宏开关区分开机末端孔及开机1号孔

# 版本号说明

## 命名方式
    vX.Y.Z-rN
  - X.Y.Z 为软件版本
  - N 为版次，需要根据此数字区别不同的修改
    eg. v2.0.0-r7 版本 2.0.0 版次 r7
    v2.0.0-r8 版本 2.0.0 版次 r8
## 软件描述
  下载口会打印: 
    程序版本 修改日期
    本软件描述 (协议)
    电路板版本 电路板描述 (最大电流)

```
 Version:v2.0.0-r7(20000007)  Time: Aug 18 2025 16:17:02
 Description:Selector Valve (AGS)
 PCB:A12_909_A2  Vertical Version (2.2A Max)
```
